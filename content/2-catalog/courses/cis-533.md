## Course Description

Introduction to the foundations of data science and data analytics. Computer science concepts used for making discoveries in data. Data wrangling, feature engineering, classification, regression, clustering, outlier detection, societal aspects of data science, and more. Analysis of real-word data.

## Credit Hours

3 credits

## Course Goals and Learning Outcomes

Upon completion of this course, students will be able to:

1. Define and profile data science problems, and solve it using machine learning and data analytics tools.
2. Understand and be able to apply basic machine learning and data analytic techniques.
3. Identify machine learning and computing strategies to approach and solve problems using data.
4. Understand discovery methods and their application to turn data into knowledge.
5. Use statistical inference to explore data and determine the significance of discoveries.

## Course Description

Knowledge and skills needed to administer and defend computer networks and systems. Topics include the basics of computer networks, intelligence gathering, network scanning and sniffing, password security and cracking, vulnerability exploitation, distributed denial of service, logging and auditing, and wireless network security and cracking. Practice using an isolated computing network.

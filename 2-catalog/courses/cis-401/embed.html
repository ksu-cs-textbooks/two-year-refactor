CIS 401 - Software Design, Implementation, and Testing

Course Description

A study of concepts and techniques used to produce quality software programs. Software design concepts, models, execution environments, design and testing techniques. Extensive application of these concepts and techniques to the development of non-trivial software programs. The course culminates with a capstone project to demonstrate core understanding.

Credit Hours

3 credits

Course Overview

This course is focused on helping you to learn the concepts and skills needed to develop high-quality software. Along the way you will have ample opportunities to practice these skills developing non-trivial software projects. These are not the “baby programs” of early CS coursework, but rather applications that could be used in a production environment.

Accordingly, our goal is not just to write software that compiles without errors, but to develop well-written and maintainable software. This goal demands extra attention to design, documentation, and testing. Additionally, we will explore some of the advanced features of programming languages and tools, as well as other professional tools like code repositories and diagramming software.

Course Goals and Learning Outcomes

By the end of this course, we expect each student to be able to:

  1. Create class definitions that (1) utilize encapsulation to organize related data and behavior, (2) prevent uncontrolled internal state changes through information hiding, and (3) allow outside code controlled interactions through message passing.
  2. Specify expected object behavior and verify it through creating and executing unit tests against a class definition.
  3. Utilize polymorphism in the form of inheritance to minimize code duplication by moving shared fields and methods to a common ancestor.
  4. Reason about dynamic dispatch to determine what version of a polymorphic function or method will be invoked at runtime.
  5. Utilize industry standard developer tools to develop software reliably and efficiently.
  6. Design, implement and test a project of your own design based on the principles covered in this course.

Assignments

Assignments in CIS 401 are designed to help students develop the skills necessary to create high-quality, maintainable software systems. Throughout the course, students will complete a series of programming projects, laboratory exercises, and testing activities that reinforce software design principles, programming techniques, debugging strategies, and professional development practices. Emphasis is placed on writing well-structured code, developing automated tests, and using industry-standard tools.

Students will progressively apply course concepts to increasingly complex software projects, culminating in a capstone project that demonstrates their ability to design, implement, test, and document a non-trivial software application. Assignments evaluate both the correctness of the software and the quality of its design, organization, maintainability, and testing practices.

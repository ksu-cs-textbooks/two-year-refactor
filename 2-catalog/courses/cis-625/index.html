CIS 625 - Concurrent Software Systems

Course Description

Architecture, design, modeling, implementation, and verification of concurrent, parallel, and distributed software; aspects such as real-time programming, parallel simulation; fault-tolerant programming; grid computing, embedded systems control.

Credit Hours

3 credits

Course Overview

Not yet drafted — pending course-designer’s detailed pass. resources/reference/degree-maps/cs.md lists this as one of three choices (with CIS 520, CIS 525) for the Year 4 Systems Elective, and confirms it as legitimate elective depth sitting on top of CIS 300’s required concurrent-algorithms/thread-safe-data-structures content — the same “required foundation, elective depth” pattern used elsewhere (e.g., CIS 560/575 on top of CIS 300/301).
